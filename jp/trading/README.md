# TradingView 注文連携

注文を送信したことと、実際の処理結果を分けて確認しました。

## 変えた流れ

信号の入力確認から注文依頼、証券会社・取引所の応答と実行結果をログ・Telegramで見る流れにしました。

## 確認した結果

過去のシグナル連携GIFと韓国投資証券・Upbitの注文結果です。収益率や現在の状態を示しません。
