# Threads 投稿管理

下書き生成だけでなく、検査・予約投稿・コメントと実行結果をつなぎました。

## 変えた流れ

生成した文を直接公開せず、長さ・禁止語・言語と重複を確認してから投稿する流れにしました。

## 確認した結果

既存ダッシュボード、GIF、コメント・日次記録・通知を確認できます。1日3回は記録上の計画であり、現在の成功率ではありません。
